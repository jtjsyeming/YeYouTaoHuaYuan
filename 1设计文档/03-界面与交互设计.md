## 1. 整体布局

站点采用 Blazor 模板经典的"左侧固定导航 + 右侧内容"双栏布局（`MainLayout.razor`）：

```
┌──────────┬──────────────────────────────┐
│          │  top-row: [About 链接]        │
│ sidebar  ├──────────────────────────────┤
│ (NavMenu)│                              │
│ 夜游桃花源│        @Body 内容区           │
│ ──────── │   (article.content px-4)     │
│ ▸ jtjsym │                              │
│ ▸ 按下试试│                              │
│ ▸ 爱情计时器│                            │
│ ▸ 2048   │                              │
│ ▸ 俄罗斯方块│                            │
└──────────┴──────────────────────────────┘
```

- 品牌名"夜游桃花源"显示在侧边栏顶部，字体 Arial。
- 导航使用 open-iconic 图标（home / pulse / heart / play-circle / code）。
- 小屏下 NavMenu 支持折叠（navbar-toggler 切换 collapse）。
- 首页页脚为全屏宽固定底栏（半透明黑底白字），展示 ICP 备案号并链接至工信部备案系统——全站合规要素。

## 3. 各页面界面与交互说明

### 3.1 首页（/）

- 结构：`<header>` 大标题"欢迎来到夜游桃花源" + `<main>`"你好！" + 固定页脚备案号。
- 交互：无。纯静态引导页。
- 改进建议：可加入各功能入口卡片、最近动态等，避免首页过空。

### 3.2 电子木鱼（/counter）

**界面元素**
- 标题"按下试试"；
- 计数文本：`次数: N`；
- 一个 48×48 圆形按钮，背景为木鱼动效图 `Images/counter.gif`；
- 点击后按钮两侧出现 24px 的 FluentIcon（同一 gif）。

**交互流程**
```
点击按钮 → knockCount+1，ShowImage=true（显示两侧 gif）
鼠标移出按钮 → ShowImage=false
按钮 :active → transform: scale(1.1) 按压放大反馈
```

**设计要点**
- 轻量解压向设计，gif 动效代替复杂动画；
- 计数不持久化，刷新归零。

### 3.3 爱情计时器（/loveTime）

**界面分区**
1. 标题"爱情计时器"；
2. 三行计时展示（class=timer）：
   - 我们相识已经过去了：…天 …小时 …分 …秒
   - 我们相爱已经过去了：…
   - 我们步入婚姻已经过去了：…
3. "输入你的时间节点和想要计算的类型"表单区：
   - 年份（1950 至今）/ 月份（1-12）/ 日期（1-31）三个 FluentSelect，宽度 120/100/100px，横向排列（date-bar）；
4. 三个 FluentButton 横排（FluentStack，间距 20，自动换行）：计算相识时间 / 计算恋爱时间 / 计算结婚时间。

**交互逻辑**
- 页面加载即计算三个内置纪念日；
- 用户选择日期后点击对应按钮，覆盖同类型显示结果；
- 日期选择未校验合法性（如 2 月 31 日会构造失败抛异常，未做 try/catch 或天数联动）。

**交互问题**
- 计时**不自动刷新**，秒数静止；需刷新页面更新；
- 建议后续：加秒级自动刷新、日期联动（按月天数生成日选项）、结果增加"X 年 X 月 X 天"的展示位（数据已计算但未渲染）。

### 3.4 2048（/game_2048）

**界面元素**
- 标题"2048"；
- 4×4 棋盘（game-container → row → tile，tile 直接显示数字）；
- 屏幕方向键盘：上排"⬆️"，下排"⬅️ ⬇️ ➡️"；
- 分数行 `Score: N`；
- "重玩"按钮；
- 游戏结束遮罩：`游戏结束` + 重玩按钮（条件渲染）。

**交互流程**
```
初始化 → 空棋盘随机放 2 块（2 或 4）
点击方向 → 对应行/列压缩合并 → AfterMove：
    放新块 → 判定结束（无空格且无可合并）→ StateHasChanged
```

**设计要点**
- 纯按钮操作，未绑定键盘方向键；
- tile 无数字区分配色（所有块同一样式）；
- 分数文案为英文 "Score"，与全站中文风格不一致。

### 3.5 俄罗斯方块（/tetris）

页面为深色主题（#0a0a0a 底），与全站浅色风格独立，营造游戏氛围。详细机制见《02-详细设计-俄罗斯方块.md》，此处只列界面：

```
┌─────────────────────────────┐
│ ┌─────────────┐ ┌────────┐  │
│ │             │ │难度等级:N│  │
│ │  10×20 网格  │ │分数: N  │  │
│ │  (30px/格)  │ ├────────┤  │
│ │  +当前块     │ │下一块预览│  │
│ │   overlay   │ ├────────┤  │
│ │             │ │暂停/继续 │  │
│ └─────────────┘ │重新开始  │  │
│                 └────────┘  │
│    [旋转]      [←] [↓] [→]  │
└─────────────────────────────┘
```

**交互细节**
- 所有操作为屏幕按钮（蓝 #0078D4 主色；继续=绿、重开=红、↓ 深蓝）；
- "↓"是唯一使用 pointer 事件的按钮：按住连续软降（50ms/格，每格 +1 分），松开/移出/离开即停；
- 暂停时显示"已暂停（禁用态）"+"继续游戏"两个按钮；
- 游戏结束时：操作按钮全部禁用，侧栏显示红色"游戏结束!"；
- 按钮有 hover 提亮/放大、active 缩小的微交互。

### 3.6 编程挑战（/coding_place，隐藏）

- FluentPage 结构：题面（problem-description）+ 大段 C++ 代码 + 输入/输出示例；
- 代码展示区（FluentCodeBlock）整体被注释，当前仅以纯文本呈现；
- 定位为个人刷题笔记页，导航隐藏。

## 4. 视觉风格规范（现状归纳）

| 项 | 现状 |
|---|---|
| 主题 | 全站浅色（Bootstrap 默认），俄罗斯方块页深色 |
| 主色 | Fluent 默认主题蓝；游戏页 #0078D4 |
| 字体 | 系统默认 + Arial（品牌名） |
| 图标 | open-iconic（导航）、Fluent Icons（木鱼页）、Emoji（2048 方向键） |
| 组件混用 | Fluent 组件（Select/Button/Stack）与原生 button/div 混用 |

## 5. 交互体验改进清单（按优先级）

1. **爱情计时器自动刷新**（体验缺口最明显）；
2. 2048/俄罗斯方块支持键盘操作（电脑端基础体验）；
3. 2048 tile 按数值配色 + 中文"分数"文案统一；
4. 日期选择合法性校验与天数联动；
5. 移动端：tetris 按钮区域已适配，但 4×4/10×20 网格使用固定像素，小屏可加 `min()`/vw 缩放；
6. 首页内容充实（功能入口卡片化）；
7. 统一组件风格：全部迁移到 Fluent UI 或全部原生，减少两套观感混杂。
