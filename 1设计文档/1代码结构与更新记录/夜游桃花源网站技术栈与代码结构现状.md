# 夜游桃花源网站技术栈与代码结构现状

> 版本：v1.3　|　更新日期：2026-11-01　|　适用范围：`jtjsym/` 工程
> 本文档描述网站**当前**的技术栈与代码结构，随代码演进持续更新；迭代历史见同目录《更新记录.md》。

## 1. 项目简介

**夜游桃花源**（工程名 jtjsym）是基于 C# Blazor 的个人小型网站，包含电子木鱼、爱情计时器、2048、俄罗斯方块等功能页。站点已完成 ICP 备案（陕ICP备2024056488号），面向公网提供 HTTPS 服务。

- 解决方案：`jtjsym/jtjsym.sln`
- 实际工程：`jtjsym/jtjsym/`（注意两层同名目录）
- 特点：无数据库、无外部服务，所有页面状态保存在服务端组件内存中，会话级生命周期。

## 2. 当前技术栈

| 类别 | 选型 | 版本/说明 |
|---|---|---|
| 运行时 | .NET | 8.0（net8.0，Nullable + ImplicitUsings 已启用） |
| Web 框架 | ASP.NET Core + **Blazor Server** | 传统托管模式：`_Host.cshtml` + `MapBlazorHub` + `MapFallbackToPage` |
| 实时渲染 | SignalR（Blazor Server 内建） | 所有交互经长连接往返服务端 |
| UI 组件库 | Microsoft.Fast.Components.FluentUI | 3.8.0（含 Icons 包），`AddFluentUIComponents()` 注册 |
| CSS 框架 | Bootstrap 5 | 模板自带，`wwwroot/css/bootstrap/` |
| 图标 | open-iconic（导航）+ Fluent Icons（组件）+ Emoji（2048 方向键） | |
| 静态库管理 | libman | `.config/dotnet-tools.json` 已声明，无需 Node/npm |
| 数据存储 | **无** | 无数据库、无持久化；分数/计数等刷新即失 |
| 定时器 | System.Timers.Timer | 俄罗斯方块游戏循环使用 |
| 配置 | appsettings.json | 仅默认日志配置，无自定义项 |
| 部署 | 文件夹发布 | `Properties/PublishProfiles/FolderProfile.pubxml`；需 .NET 8 ASP.NET Core Runtime |

**请求管道**（Program.cs）：生产环境 `/Error` 异常处理 + HSTS → HTTPS 重定向 → 静态文件 → 路由 → `MapBlazorHub` → 回退 `_Host`。

**服务注册**：`AddRazorPages`、`AddServerSideBlazor`、`AddFluentUIComponents`、`AddHttpClient`（预留）、`WeatherForecastService`（模板残留，未使用）。

### 3.4 关键运行机制备忘

1. **状态在服务端**：Blazor Server 模式下游戏棋盘、计时器都在服务器内存，用户刷新/断线即重置；改状态后需 `StateHasChanged()` 才推送渲染。
2. **Tetris 的 Timer 三重保护**：`isDisposed` 标志 + `timerLock` 互斥 + `InvokeAsync` 切回渲染上下文，组件销毁时 `Dispose()` 统一停表——新增定时逻辑应沿用此模式。
3. **无持久化**：如需存档/排行榜，需先引入存储层（SQLite 或云数据库）。
4. **VS Code 一键运行/调试**（2026-11-01 起随仓库提供 `.vscode/`）：`launch.json` 内含「jtjsym 网站 (Blazor Server)」「MineSweeper 扫雷 (WinForms)」与「同时启动」三条配置，均在 F5 前自动执行对应 `build-*` 任务；网站固定监听 `http://localhost:14074`（本机无 HTTPS 开发证书，故不用 14073）。
