> 对应 FT 证据：FT-01（五类非法档全放行）、FT-02（伪造分污染 best）、FT-03（空盘软锁）、FT-04（非法值进合并/溢出）

## 1. 四条问题一览与共同根因

| 编号 | 现象 | 直接根因 |
|---|---|---|
| P-002 | 注入 5 类非法档（负分、非 2 幂块、全零盘、int.MaxValue、999999 分）全部原样恢复 | 恢复校验仅 `st is { V:1, Cells.Length:16 }`，无内容校验 |
| P-003 | 伪造 `score=999999` 经恢复路径 `UpdateBestScore()` 写入 localStorage，**永久污染最高分**（清 session 也消不掉） | 恢复路径把存档分当"本会话真实得分"触发破纪录 |
| P-004 | 全零盘恢复后 0 块、无遮罩，四方向全"无变化"早退，**永久软锁**只能重玩 | 空盘通过校验；`AfterMove` 的"无变化不生成新块"使空盘无法自愈 |
| P-005 | `3+3→6`（非 2 幂块、`tile-6` 无配色）、`int.MaxValue×2→-2`（int 溢出负分） | 非法值进入 `Merge()`；`values[i]*2` 与 `Score +=` 无任何防护 |

**共同根因**：D-17 的恢复路径只做了结构校验，把"内容可信"当成了默认前提。而 sessionStorage 是任何同源脚本/手工/扩展都能写的——**入口必须自证合法**。

## 2. 修复方案：恢复路径三道闸

### 2.1 闸一：内容校验（根修 P-002 / P-004 / P-005）

```csharp
private const int MaxTileValue = 1 << 17;        // 131072：标准 2048 理论最大块
private const int MaxScoreValue = 4_000_000;     // 理论最大分约 3932156，取整 4M 防伪

private static bool IsValidArchive(SessionState st)
{
    if (st is not { V: 1 } || st.Cells.Length != GridSize * GridSize) return false;
    if (st.Score is < 0 or > MaxScoreValue) return false;
    var hasTile = false;
    foreach (var v in st.Cells)
    {
        if (v == 0) continue;
        if (v is < 2 or > MaxTileValue || (v & (v - 1)) != 0) return false;  // 必须为 2 幂
        hasTile = true;
    }
    return hasTile;   // 全零盘拒绝（P-004 软锁根治）
}
```

- 非 2 幂（3/6/7/int.MaxValue）→ 拒 → **P-005 的输入源头消失**，`Merge` 不会再产出 6/-2；
- 全零 → 拒 → **P-004 根治**（空盘档根本进不了棋盘）；
- 分数范围 [0, 4M] → 负分与天文数字拒。

**处置**：校验失败 → `sessionStorage.removeItem(SessionKey)`（清掉脏档防重复拒绝）+ 保持 `OnInitialized` 的新局，静默（与《16》的容错语义一致）。

**明确不在 `Merge()` 加 `checked`**：入口校验后，最大块 131072、合并至 262144，int 溢出在合法输入下不可达；加 `checked` 反而让理论性异常以 `OverflowException` 形式逃逸炸 circuit，比静默更糟。P-005 以"输入合法性"根治而非运算处堵漏。

### 2.2 闸二：恢复路径零 best 副作用（根修 P-003）

- **删除恢复分支末尾的 `UpdateBestScore()` 调用**（若有）：best 只反映**本会话真实玩出来的分数**，更新点仅保留 `AfterMove()`；
- 恢复残局后即使其分数 > BestScore，UI 也照实显示当前 BestScore；用户真实走一步得分后自然破纪录——伪造分**写不进 localStorage**，浏览器语义上"标签级污染"不再升级为"永久污染"。

### 2.3 闸三（可选双保险）：运行期空盘自愈

`AfterMove()` 内加一行：若盘面全空（正常流程不可达，仅防御未来代码路径）→ `AddRandomTile()`。列为可选项，主修复是闸一。
