## 2. 修复方案明细

### 2.1 P-008 文档表述修正

《更新记录.md》D-17 条目与《现状》中所有"两个标签各玩一局互不干扰"改为：

> "全新标签各玩一局互不干扰；**复制标签/`window.open` 会继承会话副本**（浏览器规范行为），从同一残局开始、后续写入互不影响。"

选 sessionStorage 的核心理由（"本次访问"语义）不变，仅把隔离范围的表述校准到规范语义。

### 2.2 P-011 spec 数同步

《现状》§3.1 "12 个 spec + helpers.mjs" → "14 个 spec + helpers.mjs"，并追加一句"以 `tools/e2e/tests` 目录实数为准（随测试资产演进）"，降低再次过期的概率。

### 2.3 P-012 README 重写

修正拼写（Gmae → Game），按现有导航结构补全模块清单：首页（功能入口卡片）、电子木鱼、爱情计时器、2048、俄罗斯方块；补充：技术栈一行（.NET 8 + Blazor Server + FluentUI 3.8.0）、本地运行命令（`dotnet run` 于 `jtjsym/jtjsym/`）、e2e 测试入口（`tools/e2e`，`npm test` 系列脚本）。保持简短（README 是门面不是文档站，详情指向《04-技术栈速查-README》）。

### 2.4 P-013 删未用注入

`Game_2048.razor` 删 `@inject NavigationManager Navigation` 一行；build 验证无引用残留。

### 2.5 P-015 Tetris 主标题

`Tetris.razor` 的 `<PageTitle>` 之后加 `<h1>俄罗斯方块</h1>`。**注意布局影响**：页面是深色全屏游戏布局，`h1` 会引入默认外边距与全局 `div{color:#886D68}` 之外的标题样式（H-010 的继承色隐患恰好在此显形）——样式随 `<style>` 内补一条 `.tetris-container h1 { ... 深色主题适配（白字、居中、紧凑外边距） }`，并在 §4 用例里断言 375px 无溢出（与 H-006 横屏问题无关，纵向多一行标题在竖屏余量内）。

### 2.6 P-016 既有套件补 320px 档

- `lt.spec` 的 LT-30（移动端视口矩阵）与 `code_nf.spec` 的 NF-02b 增补 320×568 视口参数（自研 FT-12/FT-14 已证明该档全绿，固化即可）；
- 顺带把 FT-12 的"三行日历副行无裁切"断言并入 LT-30 的 320 档（覆盖 D-03 新增面）。
