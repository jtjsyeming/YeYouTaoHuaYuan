## 1. 问题与现状（均已核实）

### 1.1 H-002 / D-05：备案号链接指向公安部平台

`Pages/Index.razor:63`：

```html
<a href="https://beian.mps.gov.cn/#/" target="_blank" rel="noopener">陕ICP备2024056488号</a>
```

- `beian.mps.gov.cn` 是**公安部**互联网安全管理服务平台（公安备案），而 `陕ICP备…` 是**工信部** ICP 备案号 → 张冠李戴；
- 即使是公安备案号，链接也应指向备案详情而非平台首页 `#/`；
- 站点页脚**只有 ICP 号、没有公安备案号**，所以修正方向唯一：指向 `https://beian.miit.gov.cn/`。

### 1.2 H-009：CodeAnswer 是未渲染的死字段

`Pages/MyPage/CodingPlace.razor`：

```
:11   <pre class="problem-description">@ProblemDescription</pre>
:34   private string CodeAnswer = $@"…整段 C++ 参考答案…";
```

`@CodeAnswer` 在标记中**零引用** → 页面只看得到题面。C-09 已记载。

**实测的样式事实（v2.0 新增）**：`pre.problem-description` 的 computed style 是 `color: rgb(33,33,33)`（Bootstrap 的 `pre{…color:#212529}`）、`background: rgba(0,0,0,0)`、`border: 0`、`padding: 0`，且 `problem-description` 这个类**全仓没有任何 CSS 定义**（grep 只命中这一处标记）。所以"深色代码块"在本题面里并不存在。

### 1.3 H-012：UseHttpsRedirection 在开发判断之外

`Program.cs` 实际结构：

```csharp
13  if (!app.Environment.IsDevelopment())
14  {
15      app.UseExceptionHandler("/Error");
17      app.UseHsts();
18  }
20  app.UseHttpsRedirection();     // ← 在判断之外
22  app.UseStaticFiles();
```

用 `--no-launch-profile --urls http://localhost:xxxx` 启动时没有 https 端口可推断 → 不重定向、只打告警。**已实测复现**：

```
warn: Microsoft.AspNetCore.HttpsPolicy.HttpsRedirectionMiddleware[3]
      Failed to determine the https port for redirect.
```

NF-05（http→https 301）因此只能在生产环境有确定结论。

## 2. 修复方案

### 2.1 H-002：备案链接改为工信部

```html
<a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener">陕ICP备2024056488号</a>
```

工信部备案系统没有稳定的"备案号详情直链"，指向系统首页即业界惯例。

**同步必改（两处 spec，v1.0 漏了一处）**：

| 位置 | 现状 | 改为 |
|---|---|---|
| `tools/e2e/tests/nav_fish.spec.mjs:81`（NAV-06） | `href === 'https://beian.mps.gov.cn/#/' && target === '_blank'` | `href === 'https://beian.miit.gov.cn/' && target === '_blank'` |
| `tools/e2e/tests/d15_home_fluent.spec.mjs:58`（D15-6） | `href === 'https://beian.mps.gov.cn/#/' && target === '_blank'` | 同上 |

**文档同步（含编号错位的处理）**：

- 《07》**:62**（NAV-05 行）的预期结果把 `beian.mps.gov.cn` 改为 `beian.miit.gov.cn`；
- 《07》的编号与 spec 的编号**本来就错位**：文档里 NAV-05 = 链接、NAV-06 = 页面标题；spec 里 NAV-05 = 页脚文本、NAV-06 = 链接。建议本轮把这处错位改成一致（推荐"以 spec 为准"回改《07》：NAV-05 文本、NAV-06 链接、NAV-09 或并入 NAV-07 之后补"页面标题"），否则下一个照文档改 spec 的人还会踩。

### 2.2 H-009：CodeAnswer 用折叠区展示（方案 A）

```razor
<details class="code-answer">
    <summary>参考答案（点击展开）</summary>
    <pre class="code-answer-pre">@CodeAnswer</pre>
</details>
```

**样式要自己写**（因为题面 `<pre>` 根本没有样式）：

```css
.code-answer { margin-top: 16px; }
.code-answer > summary { cursor: pointer; font-weight: 600; color: #1b6ec2; }
.code-answer-pre {
    background: #f6f8fa;          /* 浅色，与本页白底协调；深色块会和 FluentCard 打架 */
    border: 1px solid #e1e4e8;
    border-radius: 6px;
    padding: 12px;
    overflow-x: auto;             /* C++ 长行必须能横向滚，否则撑破卡片 */
    font-family: SFMono-Regular, Menlo, Consolas, monospace;
    font-size: 13px;
    line-height: 1.45;
    color: #24292f;               /* 显式给色：容器是 div，会继承 body 的 #886D68（见《25》H-010） */
    text-align: left;             /* body{text-align:center} 会继承进来 */
}
```

- **选 A（展示）而非 B（删除）**：参考答案对"编程挑战"页有真实价值，病根是"没有出口"；
- 用原生 `<details>`：零 JS、不引入未验证的 `FluentAccordion`（3.8.0 的表现本项目没测过）；
- 字段加 `readonly`（`private readonly string CodeAnswer`），**同时**给 `ProblemDescription` 也加，保持同文件一致；
- 若评审决定不展示，退化方案 B：删字段与整段文本 —— 但要在《07》C-09 条目标注"信息已弃用"，别只删了事。

### 2.3 H-012：把 `UseHttpsRedirection()` 移进已有的 `!IsDevelopment` 块

```diff
 if (!app.Environment.IsDevelopment())
 {
     app.UseExceptionHandler("/Error");
     app.UseHsts();
+    app.UseHttpsRedirection();
 }
-
-app.UseHttpsRedirection();
 
 app.UseStaticFiles();
```

- 相对顺序保持 `ExceptionHandler → Hsts → HttpsRedirection → StaticFiles`，与原来一致；
- 效果：开发环境 http-only 启动**不再刷告警**；生产行为不变（NF-05 判据不变）；
- 不要用 v1.0 的 `else` 写法：现有代码没有 `IsDevelopment()` 正分支，新造一个会让同一个判断出现两次。
